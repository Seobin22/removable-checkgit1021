# 할 일 관리 CLI

터미널에서 쓰는 간단한 할 일 관리 도구입니다. Python 표준 라이브러리만 사용하므로 따로 설치할 패키지가 없습니다.

## 설치

1. Python 3.10 이상을 설치합니다. (개발·테스트 환경: Python 3.12.10, Windows 11)
2. 이 저장소를 받습니다.
   ```bash
   git clone https://github.com/Seobin22/removable-checkgit1021.git
   cd removable-checkgit1021
   ```

> **Windows 참고**: `python`을 입력했을 때 Microsoft Store가 열리거나 "Python was not found"가 나오면,
> Python 런처인 `py`를 대신 쓰세요. 아래 예시는 모두 `py`로 적었습니다.

## 사용법

```bash
py todo.py add "장보기: 우유, 계란" --due 2026-10-25   # 마감일과 함께 추가
py todo.py add "클로드 코드 사용해 보기"                # 마감일 없이 추가
py todo.py list                                        # 목록 보기
py todo.py done 2                                      # 2번 완료 표시
py todo.py delete 1                                    # 1번 삭제
py todo.py archive                                     # 완료 항목을 보관 파일로 옮기기
```

`list` 출력 예시입니다. 마감일이 지났는데 아직 완료하지 않은 항목에는 `※ 기한 지남`이 붙습니다.

```
1. [ ] 장보기: 우유, 계란 (마감: 2026-10-01)  ※ 기한 지남
2. [ ] 주간 보고서 작성 (마감: 2026-10-24)
3. [x] 클로드 코드 사용해 보기
```

번호는 목록의 순서입니다. 항목을 삭제하거나 보관하면 뒤의 번호가 당겨집니다.

### 완료 항목 보관 (archive)

`archive`는 완료(`[x]`)된 항목을 모두 `빈파일_보관.txt`로 옮기고, 목록에는 완료하지 않은 항목만 남깁니다.
보관 파일에는 기존 내용 뒤에 보관한 날짜와 함께 덧붙여지므로, 여러 번 실행해도 이전 기록이 지워지지 않습니다.

```
완료 항목 1개를 빈파일_보관.txt에 보관했습니다.
  - 클로드 코드 사용해 보기
```

`빈파일_보관.txt` 내용 예시입니다.

```
[x] 클로드 코드 사용해 보기 | 보관일: 2026-10-21
```

## 데이터 파일

- 할 일은 `빈파일.txt`에 한 줄에 하나씩 **UTF-8**로 저장됩니다. 메모장으로 열어서 읽거나 고칠 수 있습니다.
  ```
  [ ] 장보기: 우유, 계란 | 마감: 2026-10-01
  [x] 클로드 코드 사용해 보기
  ```
- 다른 파일을 쓰려면 환경변수 `TODO_FILE`을 지정합니다. (PowerShell: `$env:TODO_FILE = "C:\경로\내할일.txt"`)
- 보관 파일은 저장 파일과 같은 폴더에 `<저장 파일 이름>_보관.txt`로 만들어집니다. (`TODO_FILE`이 `내할일.txt`이면 `내할일_보관.txt`)
- `빈파일.txt`와 `빈파일_보관.txt`는 개인 데이터라서 `.gitignore`로 저장소에서 제외했습니다.

## 오류 메시지

잘못 입력하면 Traceback 대신 무엇을 고쳐야 하는지 알려주고, 종료 코드 1로 끝납니다.

```
오류: 7번 할 일이 없습니다. (1~3번 중에서 고르세요)
오류: 번호는 숫자여야 합니다: 'abc'
오류: 날짜 형식이 올바르지 않습니다: '2026-02-30' (YYYY-MM-DD 형식의 실제 날짜로 입력하세요. 예: 2026-10-25)
오류: 빈파일.txt 2번째 줄의 마감일을 읽을 수 없습니다: ...
```

## 한글 출력

- 콘솔 화면에 바로 출력할 때는 콘솔 설정과 상관없이 한글이 정상으로 나옵니다.
- `$out = py todo.py list`처럼 출력을 변수나 파이프로 받을 때는 콘솔 코드페이지(한국어 Windows 기본값 cp949, 또는 `chcp 65001`을 실행한 UTF-8)에 맞춰 출력하므로 깨지지 않습니다.

## 테스트

```bash
py -m unittest test_todo -v
```

테스트는 임시 파일(`TODO_FILE`)을 사용하므로 `빈파일.txt`의 실제 데이터를 건드리지 않습니다.
