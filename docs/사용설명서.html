할 일 관리 프로그램

명령어 몇 개로 할 일을 적고, 끝내고, 정리하는 방법

이 프로그램은 검은 명령 창(PowerShell)에 짧은 명령을 입력해서 할 일을 관리합니다.

할 일 추가, 목록 보기, 완료 표시, 삭제, 완료한 일 정리까지 다섯 가지만 알면 됩니다. 프로그래밍을 몰라도 이 설명서의 예시를 그대로 따라 입력하면 됩니다.

대상: 컴퓨터를 일상적으로 쓰는 누구나 · 환경: Windows 10/11 · 작성일: 2026년 10월 21일

이 설명서 읽는 법

설명서에 나오는 검은 상자는 명령 창 화면을 그대로 옮긴 것입니다.

PS> py todo.py list 1. [ ] 장보기: 우유, 계란 (마감: 2026-10-01) ※ 기한 지남
  • 초록색 글자는 여러분이 입력할 내용입니다. 입력한 뒤 Enter 키를 누르세요.
  • PS>는 명령 창이 입력을 기다린다는 표시입니다. 따라 입력하지 않습니다. 실제 화면에서는 PS C:\Users\...>처럼 더 길게 보입니다.
  • 그 아래의 흰 글자는 프로그램이 보여주는 결과입니다.

1. 이 프로그램은 무엇인가요?

종이 메모장에 할 일을 적고, 끝나면 체크하고, 다 쓴 메모는 따로 모아 두듯이 같은 일을 컴퓨터로 하는 프로그램입니다.

할 수 있는 일

  • 할 일 추가: 마감일을 함께 적을 수 있습니다.
  • 목록 보기: 마감일이 지났는데 아직 못 한 일은 ※ 기한 지남으로 알려줍니다.
  • 완료 표시: 끝낸 일에 체크합니다.
  • 삭제: 잘못 적은 일을 지웁니다.
  • 보관: 끝낸 일을 별도 파일로 옮겨서 목록을 깔끔하게 유지합니다.

준비물

준비물설명
Windows PCWindows 10 또는 11
Python프로그램을 실행해 주는 무료 도구입니다. 이 프로그램을 만든 PC에는 이미 설치되어 있습니다. 다른 PC에서 쓰려면 python.org에서 내려받아 설치하세요.
프로그램 폴더todo.py 파일이 들어 있는 폴더입니다. 이 설명서에서는 바탕화면의 클로드코드 테스트 폴더를 예로 듭니다.
설치할 것이 더 있나요?

없습니다. Python만 있으면 추가로 설치하거나 설정할 것이 없습니다.

2. 시작하기 전에: 명령 창 여는 법

이 프로그램은 프로그램 폴더에서 연 명령 창에서 실행해야 합니다. 가장 쉬운 방법은 다음과 같습니다.

1

바탕화면의 클로드코드 테스트 폴더를 더블클릭해서 엽니다.

2

폴더 창 위쪽의 주소 표시줄(폴더 경로가 보이는 칸)을 한 번 클릭합니다. 경로 글자가 파랗게 선택됩니다.

3

그 자리에 powershell이라고 입력하고 Enter를 누릅니다.

4

파란색 또는 검은색 창이 열립니다. 이 창이 명령 창이고, 이미 프로그램 폴더 안에서 열린 상태입니다.

제대로 열렸는지 확인하기

아래처럼 입력해 보세요. 사용법 안내가 나오면 준비가 끝난 것입니다.

PS> py todo.py 사용법: py todo.py add "내용" [--due YYYY-MM-DD] 할 일 추가 py todo.py list 목록 보기 py todo.py done <번호> 완료 표시 py todo.py delete <번호> 삭제 py todo.py archive 완료 항목을 보관 파일로 옮기기
이런 메시지가 나오면
  • can't open file ... todo.py → 명령 창이 다른 폴더에서 열린 것입니다. 창을 닫고 1번부터 다시 하세요.
  • py를 찾을 수 없다는 메시지 → 이 PC에 Python이 설치되어 있지 않습니다. python.org에서 설치한 뒤 명령 창을 다시 여세요.
입력 요령
  • 띄어쓰기도 예시와 똑같이 입력하세요. py todo.py list에는 띄어쓰기가 두 번 있습니다.
  • 방금 입력한 명령을 다시 쓰고 싶으면 키보드의 ↑ 키를 누르세요.
  • 다 쓴 뒤에는 명령 창을 그냥 닫으면 됩니다. 할 일은 자동으로 저장되어 있습니다.

3. 할 일 추가하기

py todo.py add 뒤에 할 일 내용을 큰따옴표(" ")로 감싸서 적습니다.

PS> py todo.py add "클로드 코드 사용해 보기" 추가됨: 1. 클로드 코드 사용해 보기

마감일과 함께 추가하기

내용 뒤에 --due와 날짜를 적습니다. 날짜는 연-월-일 순서로, 숫자 사이에 빼기 기호(-)를 넣습니다.

PS> py todo.py add "주간 보고서 작성" --due 2026-10-24 추가됨: 2. 주간 보고서 작성 (마감: 2026-10-24)
이렇게 쓰세요이렇게 쓰면 안 됩니다
2026-10-2410/24, 2026.10.24, 2026년 10월 24일
2026-03-05 (한 자리 숫자는 앞에 0)달력에 없는 날짜 (예: 2026-02-30)
큰따옴표는 왜 필요한가요?

띄어쓰기나 쉼표가 들어간 내용을 한 덩어리로 묶어 주기 위해서입니다. "장보기: 우유, 계란"처럼 감싸 두면 안전합니다.

4. 목록 보기

PS> py todo.py list 1. [ ] 장보기: 우유, 계란 (마감: 2026-10-01) ※ 기한 지남 2. [ ] 주간 보고서 작성 (마감: 2026-10-24) 3. [x] 클로드 코드 사용해 보기

화면 읽는 법

표시뜻
1. 2. 3.할 일 번호입니다. 완료 표시나 삭제를 할 때 이 번호를 씁니다.
[ ]아직 하지 않은 일
[x]끝낸 일
(마감: 2026-10-24)마감일 (적은 경우에만 보입니다)
※ 기한 지남마감일이 지났는데 아직 끝내지 않은 일입니다. 마감일 당일에는 표시되지 않고, 다음 날부터 표시됩니다. 이미 끝낸 일에는 표시되지 않습니다.

할 일이 하나도 없으면 다음과 같이 나옵니다.

PS> py todo.py list 할 일이 없습니다.
번호는 바뀔 수 있습니다

번호는 목록의 순서일 뿐입니다. 중간 항목을 삭제하거나 보관하면 그 뒤의 번호가 앞으로 당겨집니다. 완료 표시나 삭제를 하기 전에는 py todo.py list로 번호를 먼저 확인하세요.

5. 완료 표시하기

py todo.py done 뒤에 목록의 번호를 적습니다.

PS> py todo.py done 3 완료: 3. 클로드 코드 사용해 보기

이미 완료한 항목에 다시 입력해도 문제없습니다. 안내만 나오고 아무것도 바뀌지 않습니다.

PS> py todo.py done 3 이미 완료된 항목입니다: 3. 클로드 코드 사용해 보기
완료를 취소하고 싶다면

완료 취소 명령은 따로 없습니다. 8장에 나오는 할 일 파일을 메모장으로 열어 해당 줄의 [x]를 [ ]로 고치고 저장하세요.

6. 삭제하기

py todo.py delete 뒤에 번호를 적습니다. 잘못 적은 할 일을 지울 때 씁니다.

PS> py todo.py delete 2 삭제됨: 2. 주간 보고서 작성
삭제는 되돌릴 수 없습니다

삭제한 할 일은 어디에도 남지 않습니다. 끝낸 일을 기록으로 남기고 싶다면 삭제 대신 완료 표시 → 보관(7장)을 쓰세요.

7. 완료한 일 정리하기 (보관)

끝낸 일이 쌓이면 목록이 길어집니다. archive(보관) 명령을 쓰면 [x]로 표시된 일을 한꺼번에 별도 파일로 옮기고, 목록에는 아직 할 일만 남깁니다.

PS> py todo.py archive 완료 항목 1개를 빈파일_보관.txt에 보관했습니다. - 클로드 코드 사용해 보기 PS> py todo.py list 1. [ ] 장보기: 우유, 계란 (마감: 2026-10-01) ※ 기한 지남 2. [ ] 주간 보고서 작성 (마감: 2026-10-24)
  • 보관한 일은 지워지지 않고 빈파일_보관.txt 파일에 보관한 날짜와 함께 쌓입니다.
  • 여러 번 보관해도 예전 기록 아래에 새 기록이 덧붙여집니다. 이전 기록은 지워지지 않습니다.
  • 보관할 완료 항목이 없으면 보관할 완료 항목이 없습니다.라고 나오고 아무것도 바뀌지 않습니다.

보관 파일 들여다보기

프로그램 폴더의 빈파일_보관.txt를 더블클릭하면 메모장으로 열립니다.

[x] 클로드 코드 사용해 보기 | 보관일: 2026-10-21
추천 사용 습관

하루를 시작할 때 list로 오늘 할 일을 보고, 하루를 마칠 때 끝낸 일을 done으로 표시한 뒤 archive로 정리하세요.

8. 할 일은 어디에 저장되나요?

모든 할 일은 프로그램 폴더 안의 두 텍스트 파일에 저장됩니다. 명령을 실행할 때마다 자동으로 저장되므로 따로 저장 버튼을 누를 필요가 없습니다.

파일내용
빈파일.txt현재 할 일 목록
빈파일_보관.txt보관한 완료 항목 (처음 보관할 때 자동으로 만들어집니다)

두 파일 모두 메모장으로 열어서 읽을 수 있습니다. 빈파일.txt는 이렇게 생겼습니다.

[ ] 장보기: 우유, 계란 | 마감: 2026-10-01 [ ] 주간 보고서 작성 | 마감: 2026-10-24

메모장으로 직접 고쳐도 되나요?

됩니다. 다만 아래 규칙을 지켜 주세요.

  • 한 줄에 할 일 하나씩 적습니다.
  • 줄 맨 앞은 [ ] (아직 안 함) 또는 [x] (완료)로 시작합니다. 괄호 뒤에 띄어쓰기 한 칸이 있습니다.
  • 마감일은 | 마감: 2026-10-24 형식을 그대로 지킵니다.
  • 고친 뒤에는 저장하고 메모장을 닫은 다음 명령을 실행하세요.

날짜를 잘못 고쳤다면 프로그램이 몇 번째 줄이 문제인지 알려줍니다(9장 참고).

백업 권장

중요한 할 일이 많다면 가끔 빈파일.txt와 빈파일_보관.txt를 다른 곳에 복사해 두세요. 이 두 파일만 있으면 모든 기록이 남습니다.

잘못 입력해도 프로그램이 망가지거나 할 일이 사라지지 않습니다. 오류:로 시작하는 안내를 읽고 다시 입력하면 됩니다.

메시지이유이렇게 하세요

오류: 번호는 숫자여야 합니다: 'abc' 번호 자리에 글자를 입력함 py todo.py done 2처럼 숫자만 입력

10. 자주 묻는 질문

Q. 컴퓨터를 껐다 켜도 할 일이 남아 있나요?

네. 할 일은 빈파일.txt 파일에 저장되어 있어서, 명령 창을 닫거나 컴퓨터를 꺼도 그대로 남습니다.

Q. 한글이 깨져 보여요.

명령 창 화면에서는 한글이 정상으로 보이도록 만들어져 있습니다. 메모장에서 파일이 깨져 보인다면 메모장의 파일 → 열기에서 인코딩을 UTF-8로 선택해 여세요. 최신 Windows 메모장은 대부분 자동으로 맞춰 줍니다.

Q. 할 일 내용에 따옴표를 넣고 싶어요.

내용 안에서는 작은따옴표(')를 쓰세요. 예: py todo.py add "'중요' 표시된 메일 답장"

명령 창이 내용 안의 큰따옴표(")를 지워 버리기 때문에, 큰따옴표는 그대로 저장되지 않습니다.

Q. 실수로 delete를 했어요. 되살릴 수 있나요?

삭제한 할 일은 되살릴 수 없습니다. 같은 내용으로 다시 add 하세요. 앞으로 기록을 남기고 싶은 일은 삭제 대신 완료 표시 후 보관하세요.

Q. 보관한 일을 다시 목록으로 가져올 수 있나요?

명령으로는 할 수 없습니다. 빈파일_보관.txt에서 해당 줄을 복사해 빈파일.txt에 붙여넣고, 줄 끝의 | 보관일: ... 부분을 지우면 됩니다.

Q. 다른 컴퓨터에서도 쓸 수 있나요?

네. 그 컴퓨터에 Python을 설치하고 프로그램 폴더를 통째로 복사하면 됩니다. 할 일도 이어서 쓰려면 빈파일.txt와 빈파일_보관.txt도 함께 복사하세요.

기억할 세 가지

  1. 명령 창은 프로그램 폴더의 주소 표시줄에 powershell을 입력해서 엽니다.
  2. 번호를 쓰는 명령(done, delete) 전에는 list로 번호를 먼저 확인합니다.
  3. 끝낸 일은 지우지 말고 done → archive로 정리하면 기록이 남습니다.
